# Sistema de Gestión de Productos en una Tienda

Trabajo Práctico 1 de Ingeniería de Software II.

Implementa un sistema básico de gestión de productos de una tienda y contiene pruebas automatizadas utilizando xUnit y Moq.

## Estructura del proyecto

- `GestionProductosTienda/`: proyecto principal de la aplicación.
- `Test/`: proyecto que contiene las pruebas automatizadas.
- `TP1.sln`: solución de Visual Studio que contiene ambos proyectos.

## Requisitos

- .NET 9 SDK
- Visual Studio o una terminal compatible con .NET

## Ejecutar el proyecto

Desde la carpeta donde se encuentra `TP1.sln`, ejecutar:

```bash
dotnet run --project GestionProductosTienda/GestionProductosTienda.csproj

## Ejecutar los tests

Desde la carpeta donde se encuentra `TP1.sln`, ejecutar:

```bash
dotnet test
